# The Tech Academy Unity Projects

This repository contains a collection of Unity projects developed as part of The Tech Academy's curriculum. Each project is contained within its own directory and showcases different concepts and techniques in Unity and C# development.

## Projects

*   **HelloWorld:** A simple project that prints "Hello, World!" to the console, demonstrating basic Unity script setup.
*   **3DCube:** A project that showcases the creation and manipulation of a 3D cube object in Unity.

## Technologies Used

*   Unity
*   C#

## What I Learned

Through these projects, I've gained a foundational understanding of the Unity editor and C# scripting. Some of the key concepts I've practiced include:

*   **Basic Scripting:** Creating C# scripts and attaching them to GameObjects to control behavior.
*   **Unity Console:** Using `Debug.Log()` to print messages for debugging purposes.
*   **3D Objects:** Creating and manipulating basic 3D primitives within a Unity scene.
